# nexus_ws — сервер чата Nexus Chat

WebSocket-релей на **Deno**. Разворачивается **локально на Vivo**.
Клиент: репозиторий **nexus_chat**. Штаб (**digital-agency**) не трогает.

- Порт: `Deno.env.get("PORT") || 8001`
- Публичный адрес через Caddy: `wss://shtab-boss.duckdns.org:8443/ws`
- Проверка: `https://shtab-boss.duckdns.org:8443/stats`

## Запуск

```bash
git clone https://github.com/alexey17001700-coder/nexus_ws
cd nexus_ws
deno run --allow-net --allow-env --allow-read main.ts
```

## Что умеет

- Комнаты = каналы чата
- История: 80 последних сообщений на комнату
- «Кто в сети» (`presence`, `welcome`, `who`)
- «Печатает…» (`typing`)
- Справочник каналов через комнату `__dir__` (замена MQTT и ntfy)
- Keep-alive пинг каждые 25 сек, чистка мёртвых соединений
- Лимит сообщения 900 КБ (фото, файлы, голосовые)
- **Telegram-уведомления** (необязательно, см. ниже)

## Протокол (клиент → сервер)

| Пакет | Назначение |
|---|---|
| `{t:"join", room, id, nick}` | войти в комнату |
| `{t:"msg", room, d}` | сообщение |
| `{t:"typing", room, nick}` | печатает |
| `{t:"dir", d:[...]}` | справочник каналов (комната `__dir__`) |
| `{t:"who", room}` | запросить список участников |
| `{t:"ping"}` | keep-alive |

**Важно:** поле называется **`t`**, а не `type`.

## Telegram-уведомления

Приходят, когда в канале новое сообщение, а Босса в этом канале нет.
Содержимое **не раскрывается** — только факт («💬 Новое сообщение · 📢 Монтажники»).
Шифрование чата не затрагивается.

### 1. Создать бота
В Telegram: **@BotFather** → `/newbot` → получить токен вида `1234567890:AAH...`

### 2. Запустить сервер с токеном

```bash
TELEGRAM_TOKEN='1234567890:AAH...' deno run --allow-net --allow-env --allow-read main.ts
```

Токен можно «закрепить», чтобы не вводить каждый раз:

```bash
echo "export TELEGRAM_TOKEN='1234567890:AAH...'" >> ~/.bashrc
source ~/.bashrc
```

### 3. Подписаться
Напиши своему боту:

```
/start ТвойНик
```

`ТвойНик` — **точно такой же ник, как в чате**. Тогда свои же сообщения
уведомлениями не дублируются.

### Команды бота

| Команда | Действие |
|---|---|
| `/start ТвойНик` | включить уведомления |
| `/stop` | выключить |
| `/status` | проверить подписку |

### Подписка, живущая после перезапуска

```bash
TELEGRAM_TOKEN='...' TELEGRAM_CHAT_ID='123456789' TELEGRAM_NICK='ТвойНик' \
  deno run --allow-net --allow-env --allow-read main.ts
```

`TELEGRAM_CHAT_ID` — узнать у **@userinfobot**.

### Настройки
- `TELEGRAM_TOKEN` — токен бота (обязателен)
- `TELEGRAM_CHAT_ID` — подписка по умолчанию (необязательно)
- `TELEGRAM_NICK` — ник для неё (необязательно)
- Троттлинг: не чаще 1 уведомления на канал в **10 сек**, остальное досылается пачкой

## Статус

`GET /stats` → поле `tg`:

```json
{"enabled":true,"subs":1,"rooms":3}
```

- `enabled` — токен задан
- `subs` — сколько подписок
- `rooms` — сколько каналов знает сервер

## ИИ-шлюз (`ai.ts`) — помощник Штаба

Отдельный процесс, отдельный порт. **Чат (`main.ts`, :8001) не затрагивает.**

```bash
deno run --allow-net --allow-env --allow-read ai.ts
```

### Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/ai/health` | какие провайдеры настроены (ключи не раскрываются) |
| `GET` | `/ai/models` | список моделей и порядок роутера |
| `GET` | `/ai/memory` | сколько памяти загружено (`?reload=1` — перечитать файл) |
| `GET` | `/ai/tools` | включены ли инструменты GitHub |
| `POST` | `/ai` | `{messages:[{role,content}], provider?, temperature?, tools?}` → ответ |

### Роутер

Пробует провайдеров по цепочке: **GLM → DeepSeek → VseGPT → OpenRouter → Groq**.
Лимит (429), мёртвый ключ (401) или ошибка — автоматом следующий.
Первого в очереди задаёт `AI_DEFAULT`.

### Память Помощника

Файл **`ai_memory.md`** рядом с `ai.ts` — читается при старте и подмешивается
в системный промпт. Там: кто такой Помощник, стиль, список проектов, сервер,
запреты. **Секретов в нём нет** — репозиторий открытый.

Правишь файл → применяешь без перезапуска:

```bash
curl "http://localhost:8002/ai/memory?reload=1"
```

Файла нет — шлюз работает на встроенной персоне.

### Настройка

Шаблон — `env.example.txt`. Скопировать в `.env` на сервере, вписать ключи,
в репозиторий `.env` **не коммитить**. Переменные: `AI_PORT`, `AI_DEFAULT`,
`GLM_KEY`, `DEEPSEEK_KEY`, `VSEGPT_KEY`, `OPENROUTER_KEY`, `GROQ_KEY`, `AI_SYSTEM`,
`GITHUB_TOKEN`, `GITHUB_OWNER`, `AI_MAX_ROUNDS`.

### Инструменты — Помощник правит файлы

Пока `GITHUB_TOKEN` и `GITHUB_OWNER` пустые, Помощник **только советует**.
Как только они заданы — у модели появляются 6 инструментов:

| Инструмент | Что делает |
|---|---|
| `list_repo_files` | список файлов в корне репозитория |
| `read_file` | прочитать файл |
| `write_file` | записать файл целиком |
| `replace_in_file` | точечная замена (фрагмент должен встречаться ровно один раз) |

Цикл: модель просит инструмент → сервер выполняет через GitHub API → отдаёт
результат обратно → модель продолжает. До `AI_MAX_ROUNDS` шагов за запрос.

**Защита (жёстко в коде):**

- `main.ts` — правки и удаление запрещены (только чтение)
- папка `backup/` — запрещена
- удаление файлов запрещено в репозиториях `digital-agency` и `window_calc`
- `replace_in_file` отказывает, если фрагмент не найден или встречается >1 раза
- все действия возвращаются в поле `actions` и видны в Штабе (🔧 N)

Отключить инструменты для конкретного запроса: `{"tools": false}`.

### Авто-режим («пинок»)

Кнопка **▶ Авто** в окне Помощника. Если ответ заканчивается меткой
`[ЭТАП N/M]` — фронт сам отправляет «продолжи этап N+1 из M» и так до строки
«Готово, Босс». Предохранитель — 12 шагов подряд, закрытие окна останавливает цикл.

## Как включить Помощника — пошагово

### Шаг 1. Получить бесплатный ключ

**GLM-4-Flash** (Zhipu) — бесплатно, регистрация по телефону, из РФ без VPN.

1. Открыть **https://bigmodel.cn** → «Sign up» / «注册».
2. Зарегистрироваться по номеру телефона, подтвердить код.
3. Личный кабинет → раздел **API Keys** → «Create new key».
4. Скопировать строку ключа (длинный набор символов).

**Если GLM не подошёл** — есть альтернативы (заполнять в `.env` те, что есть):

| Провайдер | Где брать | Нюанс |
|---|---|---|
| DeepSeek | platform.deepseek.com | платно, копейки, из РФ напрямую |
| VseGPT | vsegpt.ru | российский шлюз, есть бесплатные модели |
| OpenRouter | openrouter.ai | модели с суффиксом `:free` |
| Groq | console.groq.com | быстро, free tier |

### Шаг 2. Положить ключ на сервер

В Termux на Vivo, в папке `nexus_ws`:

```bash
cd ~/nexus_ws
cp env.example.txt .env
nano .env
```

Вписать ключ в нужную строку, например:

```
GLM_KEY=вставить_сюда_ключ
```

Сохранить: `Ctrl+O` → `Enter` → `Ctrl+X`.

> `.env` в репозиторий **не коммитится** — ключ остаётся только на телефоне.

### Шаг 2.5. Дать Помощнику доступ к файлам (необязательно)

Без этого он только советует. Чтобы правил репозитории — нужен токен GitHub:

1. GitHub → **Settings** → **Developer settings** → **Personal access tokens**
   → **Fine-grained tokens** → **Generate new token**.
2. Repository access: **All repositories**.
3. Permissions → Repository permissions → **Contents: Read and write**.
4. Скопировать токен (`github_pat_...`) и дописать в `.env`:

```
GITHUB_TOKEN=вставить_сюда_токен
GITHUB_OWNER=твой_логин_на_GitHub
```

Проверка: `curl http://localhost:8002/ai/tools` → `"enabled":true`.

### Шаг 3. Запустить шлюз

```bash
cd ~/nexus_ws
deno run --allow-net --allow-env --allow-read ai.ts
```

Проверка, что видит ключи:

```bash
curl http://localhost:8002/ai/health
```

В ответе у нужного провайдера будет `"configured":true`.

### Шаг 4. Проверить из Штаба

Открыть Штаб → кнопка **🤖 Помощник** → написать «привет».
В подписи под ответом будет видно, какой провайдер ответил.

### Если шлюз не отвечает

| Симптом | Что делать |
|---|---|
| `Помощник недоступен` | шлюз не запущен → Шаг 3 |
| `configured:false` у всех | ключ не вписан в `.env` или не передан в окружение |
| `429` от всех провайдеров | лимиты исчерпаны, подождать или добавить ещё ключ |
| Порт занят | `pkill deno` → перезапустить Штаб (8000), Чат (8001), шлюз (8002) |

## Секреты

Токены **не хранятся в репозитории**. Только переменные окружения.
Если токен попал в открытый код — **перевыпустить** у @BotFather (`/revoke`).

## Диагностика

| Симптом | Что делать |
|---|---|
| Порт занят | `pkill deno` → перезапустить Штаб (8000) и Чат (8001) |
| Уведомления не идут | `/status` боту → есть ли подписка; в `/stats` поле `tg.subs` |
| Свои сообщения дублируются | подписаться как `/start ТвойНик` — ник должен совпадать с чатом |
| `/stats` показывает `enabled:false` | токен не передан в `TELEGRAM_TOKEN` |
